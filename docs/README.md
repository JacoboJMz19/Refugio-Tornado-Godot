# Refugio ante el Tornado — base modular v1
Proyecto para Godot 4.3+. El mapa oficial original está integrado en `assets/maps/pueblo_completo.png` y no se ha rediseñado.

## Abrir
1. Descomprime el ZIP.
2. Abre Godot 4.3 o superior.
3. Importa `project.godot` y ejecuta con F6/F5.

## Controles
- WASD o flechas: movimiento en cuatro direcciones.
- Shift: correr.
- E: interactuar a corta distancia.
- Q: soltar el último ítem.

## Reglas base
6 minutos; 3 vidas; hasta 15 NPC; hasta 4 personas acompañantes/rescatables; inventario de 5; linterna, agua, botiquín, vendas, baterías y comida; tornado con destinos aleatorios y velocidad constante; trivia inicial y final de 3 preguntas.

## Estado de esta entrega
Es una primera base modular funcional en estructura, con escenas y scripts separados, sprites provisionales y audio original generado. Las colisiones perimetrales están configuradas. Aún falta dibujar y probar las colisiones precisas de cada casa/edificio, enlazar el área del refugio para contabilizar rescates, y probar/balancear en el motor Godot. No se presenta como versión final validada dentro del motor.
